# AI 行业日报看板 · AI Daily Dashboard

> 3 分钟，追上今天所有 AI 大事。

一个**零依赖、单文件**的 AI 行业新闻可视化看板。无需安装、无需构建、无需联网即可打开，适合日常速览、屏幕录制演示与个人知识管理场景。

## 📖 项目功能介绍

把当天散落各处的 AI 资讯，压缩成**一屏可读完的日报**：左边是摘要、今日头条与三张精读卡片（阅读区），右边是数据趋势、关键词云与实时时间轴（数据区）。内容超出可视区域时由**页面右侧全局滚动条**统一浏览，卡片内部永不出滚动条。

### 1. 顶部板块标签筛选器

标题下方一排板块标签（`全部 13 条` / `精选 3 条` / `模型发布 3` / `产品更新 2` / `行业动态 1` / `观点技巧 7`），是页面的主筛选入口：

- 数字以**微型徽章**呈现——选中态白底勃艮第红字，未选中态浅灰底暖灰字；
- 点击后勃艮第红高亮块**平滑滑动**到所点标签下方，而非生硬变色；
- 切换时下方新闻列表淡出 → 换内容 → 淡入；
- 「精选」标签可与板块标签**叠加生效**（半选态以勃艮第红文字提示 AND 组合）。

### 2. 今日重点摘要

当日资讯的 2–3 条主线速读，以要点列表呈现（语音与多模态进展、行业自我约束、降本增效等），并附当日数据指标胶囊条：

- `AIHOT 精选 13 条`
- `热点事件 10 个`
- `信息量较昨日 ▲ 44%`

### 3. 今日头条 / 主编精选（通栏大卡片）

摘要下方的**通栏大卡片**，是整页的视觉锚点：

- **左侧配图色块**：深炭黑 → 勃艮第红渐变矩形，叠加 18px 细网格纹理与径向高光，左上角 `TOP STORY` 线框角标；
- **右侧内容**：`主编精选 · EDITOR'S PICK` 眉题 + 25px 加粗主标题 + 一句话 AI 摘要 + 极简「阅读全文 →」箭头按钮（悬停时箭头右移 3px，点击平滑定位并高亮对应卡片）；
- 右下角附元信息：`AIHOT 收录 · 09-16 08:06 · 热点榜第 1 位`。

### 4. 新闻卡片区（三栏等宽 · 四层结构）

三张精读卡固定 **左侧 60px 基准线**（36px 序号列 + 24px 间距），右侧所有文字严格左对齐，卡内自上而下分四层：

| 层级 | 内容 | 规格 |
| --- | --- | --- |
| **① 顶部信息行** | 巨大浅灰序号 `01 / 02 / 03`（28px，`#D8D2CB`）+ 18px 加粗炭黑主标题 + 两个极简浅灰线框标签（分类 / 优先级，内嵌单色线性 SVG 图标：火箭 / 报纸 / 齿轮） | `align-items:flex-start` |
| **② 正文区（AI 划重点）** | 「✦ AI 划重点」小标 + 2–3 条带勃艮第红圆点的要点列表，关键数据加粗；14px `/ 行高 1.6`，与标题间距 16px | 替换原长段落 |
| **③ 分割线** | 极细浅灰横线 `1px solid #E8E4DF` | 上下 `margin: 20px 0` |
| **④ 底部信息行** | 左：来源 `|` 热点榜位次 `|` 信源数 `|` 时间（12px 浅灰小字）；右：纯文字 + 纯灰对勾的「标记阅读完成」 | `justify-content: space-between` |

其他卡片行为：

- 卡片外壳：纯白底、`1px solid #E8E4DF` 极细边框、12px 圆角、内部 24px 内距、卡片间距 24px，`max-width:420px` 居中排列不撑满全宽；
- **高优先级卡片**顶部带 `1px` 勃艮第红细边、左缘 3px 红色细条，打破视觉平均；
- **收藏 / 稍后阅读**：右上角书签图标默认隐藏，指针悬停卡片时浮现，点击切换为勃艮第红实心态；
- 卡片标题可点击跳转 AIHOT 详情页；
- 点击「标记阅读完成」后，状态文字与对勾转为勃艮第红，卡片底部一条**勃艮第红进度条从 0% 平滑增长到 100%**；
- 卡片区上方提供 **「全部 / 高优先级 / 中优先级」** 分段控件，与顶部标签**正交组合**（如「产品发布 ∩ 高优先级」）；「显示 n / 3 条」以小字固定在 03 卡右上角；
- 选中板块当日没有精读卡片时，展示**空态提示卡**（附「回到全部精选」按钮），不留空白。

### 5. 今日趋势面板（右侧）

| 模块 | 内容 |
| --- | --- |
| **13 条精选仪表盘** | 40px 炭黑大数字 + `TODAY'S SELECTED` + 资讯浓度圆环（conic-gradient + 环形遮罩，浅灰底环 + 勃艮第红进度，降 / 持平态自动变灰） |
| **主编短评** | 仪表盘下方一行斜体短句（前带引言引号），给冷数据加上「人味」 |
| **板块分布条形图** | 极简横向条形图：中文分类名 + 浅灰轨道条 + 勃艮第红填充（宽度 = 今日条数 / 最大值 7）+ 右侧整齐对齐的数字 + 昨日增减箭头（`↑` 红 / `↓` 灰 / `—` 持平）。**每行本身即筛选器**，选中行填充转深色并轻微加深底色 |
| **热点关键词云** | 分类克制的微弱底色：技术类浅蓝 `#EEF3FB`、资本类浅绿 `#EDF6EF`、产品类浅紫 `#F5F2FB`、观点类中性灰；字号按热度分 3 档（11.5 / 12 / 13px），最热关键词 `Siri AI` 带 5px 勃艮第红点提示；点击有按压缩放回弹 |
| **实时更新时间轴** | 垂直时间轴：浅灰竖线 + 深色小圆点，最新一条为勃艮第红圆点 + 「最新」徽标；按时间流动排列当日动态 |
| **反馈 / 有用** | 底部「有用」「反馈」两个极简线框胶囊图标按钮，点击切换为勃艮第红点亮态（`已标记有用` / `已收到反馈`） |
| **阅读进度** | 「充电电池」质感进度条（细描边 + 内高光 + 填充光泽）+ 加粗的「n / 3 篇已读」计数 + 圆形「已阅」小印章（进度 100% 时点亮为勃艮第红），可一键重置 |

### 🎨 设计风格

**现代学院风 / 勃艮第红**：暖米白画布（`#F9F8F6`）铺极低对比点状网格纹理，`#8B3A3A` 勃艮第红为唯一强调色，暖黑正文（`#222222`）、暖灰辅助字（`#7A7571`），卡片 12px 圆角 + 极轻暖调阴影。左右分区之间以一条两端透明的竖向渐变微线分隔「阅读区 / 数据区」，全部设计令牌收敛在 `:root` 语义变量中。

### ⚙️ 技术特性

- **零依赖**：HTML + CSS + 原生 JavaScript（无 React / Tailwind / 任何 CDN），图标全部为内联单色线性 SVG，无构建步骤；
- **流式画板 + 全局滚动**：画板 `width:min(1600px,100%)` 自适应视口，不再整体 `scale` 缩放；卡片高度由内容撑开（`align-items:start`），超长内容交给页面右侧全局滚动条；
- **响应式三档**：≤900px 卡片区变两列、面板落到列表下方；≤600px 变单列（文字自动换行、标签不溢出）；≤420px 进一步收窄边距；
- **无障碍**：`aria-pressed` 状态同步、`aria-label` 图标按钮、`focus-visible` 焦点环、`prefers-reduced-motion` 一键关停全部动画；
- **可维护**：内联样式按「基础样式 → 第 19–25 轮增量覆盖层」分段注释，业务逻辑拆为「筛选渲染」与「组件交互」两个独立 IIFE，互不干扰。

## 🚀 如何打开网页

**本地打开（推荐）**

- **Windows**：双击 `index.html`，或右键 → 打开方式 → 选择浏览器；
- **macOS / Linux**：在文件管理器中双击，或执行 `open index.html` / `xdg-open index.html`；
- 也可以直接把文件拖入任意现代浏览器窗口。

**部署为在线页面**

由于是纯静态单文件，可直接部署到 GitHub Pages、Vercel、Netlify、Cloudflare Pages 等平台，或把文件内容粘贴到任意支持 HTML 的托管环境。

> 提示：页面本身完全离线可用（字体走系统字体栈）；新闻卡片跳转详情、页脚来源链接需要网络。

## 🖱️ 已实现的交互功能

| 交互 | 说明 |
| --- | --- |
| **板块标签筛选** | 顶部 6 个标签（含「精选」），点击后勃艮第红高亮块以 `transition: transform .3s` 平滑滑动到位，数字徽章同步切换配色 |
| **精选叠加筛选** | 「精选」可与板块标签叠加生效，组合态以半选配色提示 AND 逻辑 |
| **板块条形图筛选** | 右侧「板块分布」每一行本身就是筛选器：点击按板块过滤，再点当前行取消；零结果行禁用并降透明度 |
| **重要程度筛选** | 「全部 / 高优先级 / 中优先级」描边胶囊分段控件，单选可取消 |
| **组合筛选** | 标签 × 板块 × 重要程度三层条件取交集，卡片计数实时更新 |
| **列表淡入淡出** | 切换任意筛选条件时，新闻列表淡出 → 换内容 → 淡入（`opacity / transform .3s ease`），带防连点保护 |
| **空态占位** | 选中板块当日无精读卡片时，展示提示卡与「回到全部精选」按钮，而非空白 |
| **阅读完成标记** | 点击卡片状态按钮，文案切换为「已完成」，文字与对勾变勃艮第红，卡片底部进度条 0% → 100% |
| **阅读进度条** | 「充电电池」质感进度条与加粗计数实时联动；分母固定为今日全部 3 条，不随筛选变化，避免误导性的 100% |
| **已阅印章** | 右下角圆形「已阅」小印章，阅读进度达 100% 时点亮为勃艮第红 |
| **重置进度** | 一键清空全部已读状态（按钮或快捷键 `0`） |
| **键盘快捷键** | `1` / `2` / `3` 标记对应卡片已读（带可见性守卫：被筛选隐藏的卡片不响应），`0` 重置全部 |
| **收藏 / 稍后阅读** | 卡片右上角书签图标，悬停卡片时浮现（默认隐藏），点击切换收藏态并常驻显示 |
| **今日头条联动** | 「阅读全文 →」平滑滚动到对应卡片并触发一次对勾弹跳高亮 |
| **关键词胶囊按压** | 点击热点关键词胶囊触发按压缩放回弹，支持连续点击重播动画 |
| **有用 / 反馈** | 右侧栏底部两个线框图标按钮，点击点亮为勃艮第红并更新文案 |
| **卡片悬浮反馈** | 指针悬停卡片时边框加深、阴影增强（不位移，保持网格对齐） |
| **顶部滚动进度条** | 页面顶部 2px 勃艮第红渐变条，随页面滚动位置 0 → 100% |
| **外链跳转** | 新闻标题、今日头条与页脚来源可点击，新窗口跳转 AIHOT 详情页 |
| **响应式适配** | ≤900px 两列 / ≤600px 单列（趋势面板移至列表下方、时间轴与反馈按钮自适应）；≤420px 标签与胶囊自动换行不溢出 |
| **无障碍** | `aria-pressed` / `aria-label` / `focus-visible` / `prefers-reduced-motion` 全套支持 |

## 🔭 后续可以扩展的功能建议

以下按实现成本从低到高排列，欢迎按需取用：

1. **本地持久化**：用 `localStorage` 保存阅读状态、收藏清单与筛选偏好，刷新后不丢失；可进一步按日期归档「今日已读」。
2. **关键词联动**：点击热点关键词胶囊时，反向筛选出包含该关键词的卡片（当前仅为按压反馈，尚未与列表联动）。
3. **时间轴联动**：点击时间轴某条动态，定位到对应卡片或展开该事件的完整信源脉络。
4. **数据动态化**：把新闻数据抽为内嵌 JSON 配置，配套一个小脚本每日从 AIHOT 公开 API 拉取并回写 `index.html`，实现「一键日报生成」；今日头条、关键字云与时间轴也可一并由配置驱动。
5. **更多日期**：支持查看历史日报（日期切换器 + 多日数据集），趋势面板改为近 7 日折线图。
6. **搜索与全文检索**：新增搜索框，跨标题、要点、来源做全文匹配。
7. **深色模式**：跟随 `prefers-color-scheme` 自动切换，并提供手动开关（`:root` 语义令牌已就位，换肤成本低）。
8. **导出与分享**：一键导出当日已读清单 / 收藏清单为 Markdown 或图片（Canvas 截图）。
9. **多语言**：抽取文案为 i18n 字典，支持中英切换。
10. **RSS / 通知**：配合 Service Worker 或简单后端，实现「高优先级新闻」的定时推送。
