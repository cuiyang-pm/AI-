# AI 行业日报看板 · AI Daily Dashboard

> 3 分钟，追上今天所有 AI 大事。

一个**零依赖、单文件**的 AI 行业新闻可视化看板。无需安装、无需构建、无需联网即可打开，适合日常速览、屏幕录制演示与个人知识管理场景。

## 📖 项目功能介绍

把当天散落各处的 AI 资讯，压缩成**一屏可读完的日报**：左边是摘要与新闻卡片（阅读区），右边是数据趋势（数据区），整体按 16:9 画板排布，开屏即是完整一屏。

### 1. 顶部板块标签筛选器

标题下方一排板块标签（`全部 13 条` / `精选 3 条` / `模型发布 3` / `产品更新 2` / `行业动态 1` / `观点技巧 7`），是页面的主筛选入口：

- 数字以**微型徽章**呈现——选中态白底勃艮第红字，未选中态浅灰底暖灰字；
- 点击后勃艮第红高亮块**平滑滑动**到所点标签下方，而非生硬变色；
- 切换时下方新闻列表淡出 → 换内容 → 淡入；
- 「精选」标签可与板块标签**叠加生效**（半选态以勃艮第红文字提示 AND 组合）。

### 2. 今日重点摘要

当日资讯的 2–3 条主线速读，以要点列表呈现（语音与多模态进展、行业自我约束、降本增效等），并附当日数据指标胶囊条：

- `AIHOT 精选 13 条`
- `热点事件 10 个`
- `信息量较昨日 ▲ 44%`

### 3. 新闻卡片区（含优先级筛选）

- **三条精读卡片**：第一条为**头条大卡**，其余两张为次级卡片；每张卡片顶部有一条 1px 渐变发丝线，底色为微弱米白（与纯白面板形成细腻层次），悬浮时上浮并加深阴影；
- 每张卡片包含 **「重要程度」描边胶囊标签**（高 / 中）、关键数据、**带小圆点的来源胶囊**与发布时间；
- 卡片标题可点击跳转至 AIHOT 详情页；
- 点击「标记阅读完成」后，卡片底部一条**勃艮第红阅读进度条从 0% 平滑增长到 100%**，按钮切换为实心红底白字「已完成」；
- 卡片区上方提供 **「全部 / 高优先级 / 中优先级」** 分段控件，与顶部标签**正交组合**（如「产品发布 ∩ 高优先级」），并实时显示「显示 n / 3 条」；
- 选中板块当日没有精读卡片时，展示**空态提示卡**（附「回到全部精选」按钮），不留空白。

### 4. 今日趋势面板（右侧）

| 模块 | 内容 |
| --- | --- |
| **13 条精选仪表盘** | 40px 勃艮第红大数字 + `TODAY'S SELECTED` + 期号胶囊（`VOL. 013 · 09 / 16 · WED`，位于大标题行最右） |
| **主编短评** | 仪表盘下方一行斜体短句（前带引言引号），像便利贴一样给冷数据加上「人味」与观点 |
| **今日资讯浓度** | **圆环进度条**（conic-gradient + 环形遮罩实现，浅灰底环 + 勃艮第红进度），降 / 持平态自动变灰 |
| **板块分布** | 垂直列表：中文分类名 + 今日数字 + 昨日增减箭头（`↑` 红 / `↓` 灰 / `—` 持平），数字旁附 **40×4px 迷你进度条**，长度与条数成正比（随筛选实时联动） |
| **热点关键词** | 8 个豆沙底红字胶囊，`flex-wrap` 流式排列，点击有按压缩放回弹 |
| **阅读进度** | **「充电电池」质感进度条**（细描边 + 内高光 + 填充光泽）+ 加粗的「n / 3 篇已读」计数 + 圆形「已阅」小印章（进度 100% 时点亮为勃艮第红），可一键重置 |

### 🎨 设计风格

**现代学院风 / 勃艮第红**：暖米白画布（`#F9F8F6`）铺极低对比点状网格纹理，`#8B3A3A` 勃艮第红为唯一强调色，暖黑正文（`#222222`）、暖灰辅助字（`#7A7571`），卡片 12px 圆角 + 极轻暖调阴影。左右分区之间以一条两端透明的竖向渐变微线分隔「阅读区 / 数据区」，全部设计令牌收敛在 `:root` 语义变量中。

### ⚙️ 技术特性

- **零依赖**：HTML + CSS + 原生 JavaScript，无任何外部库、CDN、字体或图标请求，无构建步骤；
- **16:9 画板**：桌面端为 1600×900 等比缩放舞台，任意窗口尺寸都以完整一屏呈现，录屏友好；
- **响应式**：≤860px 自动切换单列流式布局，≤420px 进一步收窄（375px 实测无横向溢出）；
- **无障碍**：`aria-pressed` 状态同步、`focus-visible` 焦点环、`prefers-reduced-motion` 一键关停全部动画；
- **可维护**：保留 207 个 `data-page-node-id` 结构标记，便于可视化编辑器二次编辑。

## 🚀 如何打开网页

**本地打开（推荐）**

- **Windows**：双击 `index.html`，或右键 → 打开方式 → 选择浏览器；
- **macOS / Linux**：在文件管理器中双击，或执行 `open index.html` / `xdg-open index.html`；
- 也可以直接把文件拖入任意现代浏览器窗口。

**部署为在线页面**

由于是纯静态单文件，可直接部署到 GitHub Pages、Vercel、Netlify、Cloudflare Pages 等平台，或把文件内容粘贴到任意支持 HTML 的托管环境。

> 提示：页面本身完全离线可用；新闻卡片跳转详情、页脚来源链接需要网络。

## 🖱️ 已实现的交互功能

| 交互 | 说明 |
| --- | --- |
| **板块标签筛选** | 顶部 6 个标签（含「精选」），点击后勃艮第红高亮块以 `transition: transform .3s` 平滑滑动到位，数字徽章同步切换配色 |
| **精选叠加筛选** | 「精选」可与板块标签叠加生效，组合态以半选配色提示 AND 逻辑 |
| **板块行筛选** | 右侧「板块分布」每一行本身就是筛选器：点击按板块过滤，再点当前行取消；零结果行禁用并降透明度 |
| **重要程度筛选** | 「全部 / 高优先级 / 中优先级」描边胶囊分段控件，单选可取消 |
| **组合筛选** | 标签 × 板块 × 重要程度三层条件取交集，计数实时更新为「显示 n / 3 条」 |
| **列表淡入淡出** | 切换任意筛选条件时，新闻列表淡出 → 换内容 → 淡入（`opacity / transform .3s ease`），带防连点保护 |
| **空态占位** | 选中板块当日无精读卡片时，展示提示卡与「回到全部精选」按钮，而非空白 |
| **阅读完成标记** | 点击卡片按钮，文案切换为「已完成」，按钮变实心红底白字，整卡降透明度至 0.6，卡片底部勃艮第红进度条 0% → 100% |
| **阅读进度条** | 「充电电池」质感进度条与加粗计数实时联动；分母固定为今日全部 3 条，不随筛选变化，避免误导性的 100% |
| **已阅印章** | 右下角圆形「已阅」小印章，阅读进度达 100% 时点亮为勃艮第红，增加仪式感 |
| **重置进度** | 一键清空全部已读状态（按钮或快捷键 `0`） |
| **键盘快捷键** | `1` / `2` / `3` 标记对应卡片已读（带可见性守卫：被筛选隐藏的卡片不响应），`0` 重置全部 |
| **关键词胶囊按压** | 点击热点关键词胶囊触发按压缩放回弹，支持连续点击重播动画 |
| **卡片悬浮反馈** | 指针悬停时卡片上浮 4px、边框加深、阴影增强 |
| **顶部滚动进度条** | 页面顶部 2px 勃艮第红渐变条，随页面滚动位置 0 → 100% |
| **外链跳转** | 新闻标题与页脚来源可点击，新窗口跳转 AIHOT 详情页 |
| **响应式适配** | ≤860px 切换移动端单列布局（趋势面板移至新闻列表下方）；≤420px 标签与胶囊自动换行不溢出 |
| **无障碍** | `aria-pressed` / `focus-visible` / `prefers-reduced-motion` 全套支持 |

## 🔭 后续可以扩展的功能建议

以下按实现成本从低到高排列，欢迎按需取用：

1. **本地持久化**：用 `localStorage` 保存阅读状态与筛选偏好，刷新后不丢失；可进一步按日期归档「今日已读」。
2. **关键词联动**：点击热点关键词胶囊时，反向筛选出包含该关键词的卡片（当前仅为按压反馈，尚未与列表联动）。
3. **数据动态化**：把新闻数据抽为内嵌 JSON 配置，配套一个小脚本每日从 AIHOT 公开 API 拉取并回写 `index.html`，实现「一键日报生成」；期号胶囊（VOL. 013）与主编短评也可一并由配置驱动。
4. **更多日期**：支持查看历史日报（日期切换器 + 多日数据集），趋势面板改为近 7 日折线图。
5. **搜索与全文检索**：新增搜索框，跨标题、摘要、来源做全文匹配。
6. **深色模式**：跟随 `prefers-color-scheme` 自动切换，并提供手动开关（当前为浅色主题；`:root` 语义令牌已就位，换肤成本低）。
7. **导出与分享**：一键导出当日已读清单为 Markdown / 图片（Canvas 截图），便于分享到群聊或笔记工具。
8. **多语言**：抽取文案为 i18n 字典，支持中英切换。
9. **RSS / 通知**：配合 Service Worker 或简单后端，实现「高优先级新闻」的定时推送。

## 🧪 开发与验证

改样式容易，改坏交互不容易被发现。项目在开发期保留了一套自动化验证脚本，位于工作目录 `.workbuddy/`（开发辅助，不属于交付物）：

- **交互回归测试**（`check-dashboard.mjs`）：基于 jsdom 加载真实 DOM、模拟点击与键盘事件，覆盖页面结构、三层筛选组合、已读状态共存、键盘守卫、设计令牌等 **216 项断言**；
- **渲染取证**（`shots/` + Playwright 驱动本机 Edge 截图）：校验滑动指示器落位、圆环 / 迷你进度条填充比例、375px 小屏横向溢出（实测 0px）与分区微线像素渲染。

```bash
# 运行交互回归测试（需 Node.js + jsdom）
node .workbuddy/check-dashboard.mjs
```

> 💡 测试脚本中的 jsdom 依赖指向开发机上的安装位置，迁移到其他环境时需按实际路径调整。
